# Бункер — готовая сборка

Для запуска нужна **Java 21** (или новее). Maven и Docker не требуются.

1. Распакуйте ZIP в отдельную папку целиком.
2. На Windows запустите `start.cmd`. На Linux или macOS выполните `sh start.sh`.
3. Откройте http://localhost:8080 в браузере. Оставьте терминал открытым на время игры.
4. Для остановки нажмите **Ctrl+C**.

Можно запустить сервер напрямую из папки сборки:

```sh
java -jar bunker-server.jar
```

Для другого порта:

```sh
java -jar bunker-server.jar --server.port=8090
```

Команды `start.cmd` и `start.sh` тоже принимают параметр `--server.port=8090`.
На Windows `start.cmd` задаёт рабочую папку для сокетов Java, чтобы избежать ошибки
«Unable to establish loopback connection».

Участникам нужна только ссылка на сервер и код комнаты. В одной локальной сети
отправьте друзьям адрес вида `http://192.168.1.25:8080`, подставив IP компьютера
организатора. Разрешите подключение в брандмауэре частной сети, если система
запросит доступ. Для удалённой игры нужен доступный друзьям сервер или общая VPN.

Комнаты находятся в памяти: перезапуск сервера удаляет текущие партии.
Личные наборы правил сохраняются отдельно в браузере и экспортируются в `.bunker`.
Файл `schemas/bunker.schema.json` описывает формат для редактирования таких наборов.

Исходники, полная инструкция и новые выпуски:
https://github.com/spechurkin/bunker-selfhost
